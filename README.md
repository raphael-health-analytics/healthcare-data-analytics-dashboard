# healthcare-data-analytics-dashboard
Healthcare analytics portfolio project exploring emergency department wait times, patient satisfaction and referral patterns using Excel and Power BI.
## Project Overview
This project explores healthcare service utilization and patient experience through an interactive dashboard with Microsoft Power BI, supported by Excel analysis and Power Query data preparation. <br>
The analysis examines emergency department waiting times, patient satisfaction scores, and department referral patterns across patient demographic groups.
## Project Objectives
- Analyze average emergency department waiting times by patient race.
- Compare average patient satisfaction scores across racial categories.
- Examine patient record distribution across department referral categories.
- Explore referral patterns by patient race.
- Build an interactive dashboard that allows users to investigate results using demographic and admission-date filters.
## Tools and Technologies
- Microsoft Excel: Data analysis, calculations, statistical analysis, and dashboard preparation.
- Power Query: Data quality checks and data preparation.
- Power BI: Interactive visualizations, KPI cards, and report design.
- DAX: Measures for patient counts and average healthcare indicators.
- GitHub: Project documentation and portfolio presentation.
## Dataset Overview
The analyzed dataset contains 9,216 patient records. Of these, 2,517 have recorded patient satisfaction scores. <br>
The analysis includes patient demographics, emergency department waiting times, satisfaction scores, and department referral categories. <br>
Dataset source: https://www.kaggle.com/search?q=hospital+ER+Data+in%3Adatasets

The report includes slicers for:
- Patient race
- Patient gender
- Patient age
- Patient admission date
These filters enable users to explore the available records across different demographic groups and admission periods.
## Data Preparation and Quality Checks
Power Query was used to inspect and prepare the data before building the report. <br>
The analytical workflow also included checking data types, reviewing missing values, validating aggregations, and comparing dashboard totals with the earlier Excel analysis. <br>
Missing satisfaction scores were kept distinct from actual scores rather than being treated as zero. <br>
The referral category labelled "None" was retained as a separate category because its precise operational meaning requires verification.

## Limitations
The analysis describes patterns within the available dataset. It does not establish causal relationships, determine the quality of individual clinical decisions, or demonstrate that observed differences apply to all healthcare settings. <br>
Missing data and the meaning of individual referral categories should be considered when interpreting results.
